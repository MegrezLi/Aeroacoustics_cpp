# 2026-10-07：四项审查问题修复

基线为 `90bc40778fed432061d449177550e5273b35bfb9`。本轮只处理 2026-09-30 审查确认的四个问题。

| 问题 | 修复后行为 |
| --- | --- |
| ReceiverDT 粗化丢失声能峰值 | LAeq、百分位和风速分箱使用原始到达时刻及风速折点的合并网格；CSV/AM 保留各自的接收采样网格 |
| C ABI 接受 NaN 频率并返回成功 | 校验频率、对应 op 使用的物理字段及计算输出；出错返回非零并保留输出缓冲区和成功调用计数 |
| db_sum 把 NaN 当成静音 | 求最大值前检查全部声级；NaN/+Inf 报错，空列表/全 −Inf 仍表示静音 |
| 部分静音百分位产生人为声级下限 | 显式计算最小声能平台的持续时间；属于静音概率质量的分位数精确返回 −Inf |

对时刻 `[0,0.1,0.2]` s、相对声能 `[1,100,1]` 的复现案例，`ReceiverDT=0.1/0.2/0.07/0.125` s 均得到 **17.032913781186615 dB**。新增移动声源测试同时覆盖不同路径时延、窗口裁剪、背景声能和跨风速箱积分。静音案例 `{t:[0,9,10], p:[0,0,100]}` 的 L50/L95 均返回 −Inf。

C ABI 的操作编号、参数数组布局和 op7 TNO 输入速度比语义不变。有符号速度比仍取其幅值，非正 Cf 仍关闭相应声源侧；未使用字段不会因包含 NaN 哨兵而被拒绝。新增测试还检查多通道失败不产生部分输出、错误信息清除和有限输入计算溢出的错误返回。

统计的能量守恒针对已给定的分段线性宽带声能历史。独立音调的多普勒、频率计权与空气吸收仍在离散统计折点上计算，保留源采样误差；本轮没有引入连续运动音调积分或 AM 抗混叠滤波。频率和源采样收敛仍需按具体工况检查。详见 [统计口径](engineering.md#receiver-metrics)。
